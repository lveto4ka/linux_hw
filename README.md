# linux_hw3
Задание 1
Напишите скрипт, который проверяет формат файла CSV/TSV-файл и далее проверяет их на корректность (одинаковое количество столбцов в каждой строке).

Задание 2
Напишите скрипт, который создает резервные копии всех .txt файлов в директории, переименовывая их с добавлением даты.

Задание 3
Создайте скрипт, который находит 10 самых частых слов в текстовом файле.

Задание 4
Задача: Создайте скрипт, который генерирует отчет о файлах в директории: количество файлов по типам, общий размер.

Задание 5
Создайте скрипт, который читает файл с оценками студентов (содержит 3 колонки - ФИО студента, оценка, предмет) и выводит студентов с оценкой выше заданного порога по каждому предмету).

Задание 6
Используя цикл for, пропинговать список хостов и вывести результаты. Для этого необходимо использовать команду ping. 

Задание 7
Создать скрипт обратного отсчета с анимацией. Для анимации можно использовать строку из звездочек. На вход скрипт принимает число и отсчитывает от него до 0 выводя нужное количество символов в каждой новой строке.
