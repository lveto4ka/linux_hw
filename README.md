# linux_hw2
Практическая работа на занятии
1. Написать скрипт, который принимает от пользователя аргумент -u или -l и слово (порядок фиксирован). Скрипт выводит слово заглавными буквами, если использовался аргумент -u; и строчными, если -l
2. Написать скрипт, который меняет расширение файла. Первый аргумент - путь до файла, второй аргумент - актуальное расширение, третий - желаемое. Скрипт поддерживает работу только с форматами txt, pdf и doc. Если пользователь вводит отличный формат, то скрипт должен вывести сообщение об ошибке и список поддерживаемых форматов
3. Программа проверяет количество введённых пользователем аргументов. Если число аргументов отлично от 3, то выводится сообщение об ошибке, а если равно, то выводит сообщение о начале обработки
4. Программе в качестве аргумента подаётся путь до файла. Программа должна проверить, что перед ней FASTA файл и выдать сообщение об ошибке, если это не FASTA

Домашнее задание

5. Программе в качестве первого аргумента подаётся файл. Нужно проверить, существует ли он. Если файл существует, то нужно создать мягкую ссылку на этот файл в рабочей директории, используя имя файла.
6. Программе в качестве первого аргумента подаётся файл. В качестве второго аргумента вводится название организма: human, mouse, rat или fly. Программа выводит сообщение вида “Обрабатываю $ИМЯ_ФАЙЛА”. В случае, когда организм не поддерживается, программа выводит сообщение об ошибке и список поддерживаемых организмов. В случае, когда файла не существует, программы выводит сообщение об ошибке.
7. Пользователь подаёт на вход файл. Если файл - это директория, то скрипт выводит список файлов в директории, в противном случае - подробную информацию о файле и число строк. В случае, когда файла не существует, программы выводит сообщение об ошибке.
